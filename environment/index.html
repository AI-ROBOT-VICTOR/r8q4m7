개발 환경 구축

1. Network Configuration 확인

  • MSI Katana 노트북 IP, 개인 노트북 IP, Doosan Robot IP, RG2 Gripper IP address 확인
  • 각 장비 별 어떤 방식으로 서로 연결되어 있는지 꼭 확인해보자!!! (Physical & Logical Connection)
  • 노트북 IP Address 설정
  • 설정 후 ping안되는 경우 네트워크 재시작 명령어 (cli 명령어) 
systemctl restart NetworkManager

2. Doosan Robot과 ONROBOT RG2 Gripper Network 확인

  • 노트북에서 Doosan Robot으로 ping 테스트 : ping 192.168.1.100
  • 노트북에서 RG2 Gripper로 ping 테스트 : ping 192.168.1.1

  • 만약 ping했는데 reply가 안된다면? 어떻게 해야 할까?
