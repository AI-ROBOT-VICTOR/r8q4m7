Container 내부 환경 Setup

  1. yolo를 이용해서 학습시킬 경우 Container 내부에서 진행하기 위해 yolo_train 디렉토리 생성

  2. cobot2.zip 다운로드 후 아래와 같이 압축풀고 디렉토리 구조 만들기 

    docker run -d --name yolo-detection -w /ws \
--network host --gpus all --shm-size=8g \
-e ROS_DISTRO=jazzy -e RMW_IMPLEMENTATION=rmw_cyclonedds_cpp \
-e ROS_DOMAIN_ID=${ROS_DOMAIN_ID:-0} -e CYCLONEDDS_URI=file:///cyclonedds.xml \
-e PYTHONUNBUFFERED=1 \
-v ~/.config/cyclonedds/cyclonedds.xml:/cyclonedds.xml:ro \
-v ~/cobot2_ws/src/cobot2/yolo_container:/ws/src \
-v ~/yolo_train:/train \
ros:jazzy-ros-base-noble sleep infinity

  3. 옵션 설명

    • -d : 백그라운드 상주
    • --name yolo-detection : 이름(별칭)
    • -w /ws : 컨테이너 작업 디렉토리(colcon 워크스페이스 루트)
    • --network host : host 네트워크 공유
    • --gpus all : GPU 명시(GPU가 여러 장인 경우 0,1,,3... 등으로 지정)
    • -e ROS_DISTRO=jazzy : echo $ROS_DISTRO와 동일한 역할
    • -e RMW_IMPLEMENTATION : echo $RMW_IMPLEMENTATION
    • --e ROS_DOMAIN_ID : echo $ROS_DOMAIN_ID
    • -e CYCLONEDDS_URI : echo $CYCLONEDDS_URI
    • -e PYTHONUNBUFFERED=1 : docker logs 실시간 확인
    • -v cyclonedds.xml:ro : cyclonedds xml을 읽기 전용으로 마운트
    • -v yolo_container:/ws/src : host 에서 고친 코드가 컨테이너에 즉시 반영(재빌드 필요)
    • --shm-size=8g : 학습 시 DataLoader 공유메모리
    • -v ~/yolo_train:/train : 데이터셋 + 학습 산출물(runs/) 을 host 에 보존
    • sleep infinity : PID 1 컨테이너 상주 — 노드는 docker exec 로 수동 기동

  4. 실행되어 있는 Container 접속 

    docker exec -it yolo-detection bash

  5. Container 내부 개발환경 및 ROS2 의존 패키지 설치(pip도 설치) 

    apt-get update && apt-get install -y --no-install-recommends \
build-essential python3-dev python3-pip \
python3-colcon-common-extensions python3-rosdep \
ros-$ROS_DISTRO-rosidl-default-generators \
ros-$ROS_DISTRO-cv-bridge ros-$ROS_DISTRO-sensor-msgs \
ros-$ROS_DISTRO-rmw-cyclonedds-cpp

  6. Numpy, PyTorch, Torchvision, Ultralytics, OpenCV 등 설치 

    pip install --break-system-packages --ignore-installed "numpy<2"
pip install --break-system-packages --index-url https://download.pytorch.org/whl/cu128 torch==2.11.0 torchvision==0.26.0
pip install --break-system-packages "ultralytics<9" "opencv-python<4.10"
python3 -c "import numpy; assert numpy.__version__.startswith('1.'), numpy.__version__; assert '/usr/local/' in numpy.__file__, numpy.__file__"

  7. ROS2 의존성 자동설치
    • Ultralytics와 Numpy 제외 

    rosdep init 2>/dev/null || true; rosdep update
source /opt/ros/$ROS_DISTRO/setup.bash
rosdep install --from-paths src --ignore-src --rosdistro "$ROS_DISTRO" -y --skip-keys "ultralytics numpy"
colcon build --merge-install
source install/setup.bash
ros2 run object_detection object_detection

  8. Yolo-detection Container 검증 

    docker exec yolo-detection bash -c '
set +u
source "/opt/ros/${ROS_DISTRO}/setup.bash"
source /ws/install/setup.bash
exec python3 -c "$0"
' "import torch, torchvision, ultralytics, cv2, numpy
from od_msg.srv import SrvDepthPosition
import object_detection.yolo, object_detection.realsense, object_detection.detection
assert numpy.__version__.startswith('1.'), numpy.__version__
print('  import OK — numpy', numpy.__version__)"
